# EZ4 Kernel Modding Guide

Officially, EZ-Flash team support skin and help text modifications, but there are a lot of other modifications for the EZ4 kernel has been posted on various forums and websites on the internet.

Official EZ-Flash Customize Pack: https://www.ezflash.cn/zip/EZPDA_1.7.5.zip

> [!NOTE]
> The Official Customize Pack does not include latest EZ4 kernel 2.05.  
> It can still be used by replacing the kernel to latest kernel version.
