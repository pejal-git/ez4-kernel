
## Tools
Tools for EZ4 kernel modding is originally built for Windows operating system.  
For Linux users, `wine` is required to run these tools.

---

#### 1. Windows Tools
Windows tools should be obtainable from the internet via various source.

| Name            | Description    | Official / Alternate Sources    | Usage |
|-----------------|----------------|------------|-------|
| RomBuildPro.exe | Rom Builder    | Included in most skin builder, e.g. : <br>- [Official Cuztomize Pack](https://www.ezflash.cn/zip/EZPDA_1.7.5.zip)<br>- [EZ-Flash 4 Skin Builder](https://gbatemp.net/threads/ez-flash-4-skin-builder.477287/)<br>- [EZ4 Skin Builder by draxoon](https://gbatemp.net/threads/ez4-loader-1-76-released-some-bug-fixes.384174/page-4#post-5420170) | Building the EZ4 kernal binary |
| pictrans.exe    | Graphic Viewer | https://www.irfanview.com/               | Converts modern images into uncompressed, legacy indexed-color BMPs compatible with the GBA asset compiler. |
| batgba.exe      | GBA Emulator   | https://batgba.zophar.net/               | Test-run modded kernel before flashing into GBA/NDS |
| Lunar IPS.exe   | IPS patcher    | https://fusoya.eludevisibility.org/lips/ | Patch modded kernel with desired modifications. e.g. text patch, etc. |

---

#### 2. Linux Tools
Linux tools requires you to download and install them first. Refer to the original documentations:  
GIMP - https://www.gimp.org/  
Wine - https://www.winehq.org/  

TextEditor is not necessarily required to be obtained, you may use any text editor available,  
e.g: nano, vim or any visual text editor. But recommended:  
Sublime Text - https://www.sublimetext.com/

| Name 	     | Description               | Usage                                     |
|------------|---------------------------|-------------------------------------------|
| GIMP 	     | Image Editor 	           | Customize or create new skin source image |
| wine 	     | Translate Windows program | Run windows executable tools              |
| TextEditor | Text editor 	             | Modify help.txt for EZ Flash IV kernel    |
